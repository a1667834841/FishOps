### Step 4: 检查 Network 面板

1. **打开 Network 面板** (F12)
2. **清空现有日志** (点击清除按钮 🗑️)
3. **触发自动回复**（发送 "123"）
4. **查找请求**

**应该看到：**
- URL: `https://www.goofish.com/r/MessageSend/sendByReceiverScope`
- Method: `POST`
- Status: 应该是 `200` 或其他成功状态码

**如果没有看到这个请求：**
- ❌ 说明 fetch 没有被调用 → 代码有问题
- ❌ 请求被浏览器拦截 → 检查 CSP 或权限
- ❌ 请求发送失败 → 查看错误信息

## ⚠️ 常见问题及解决方案

### Q1: 没有看到 Network 请求

**可能原因：**
- 扩展未正确注入
- XianyuSender 未定义
- 代码执行顺序问题

**解决方案：**
```javascript
// 1. 检查是否定义了 XianyuSender
console.log(window.XianyuSender);

// 2. 如果没有定义，手动加载脚本
var script = document.createElement('script');
script.src = chrome.runtime.getURL('inject/api/chat-sender.js');
document.head.appendChild(script);

// 3. 等待加载完成后重试
setTimeout(() => {
  console.log('XianyuSender 已加载:', !!window.XianyuSender);
}, 1000);
```

---

### Q2: Fetch 请求失败 - CORS 错误

**错误信息：**
```
Access to fetch at '...' from origin '...' has been blocked by CORS policy
```

**原因：** 跨域限制

**解决方案：**
由于是同源请求（都是 goofish.com），理论上不应该有 CORS 问题。如果出现：

1. **检查是否在正确的域名下**
   ```javascript
   console.log(location.hostname); // 应该是 www.goofish.com
   ```

2. **尝试添加更多 headers**
   ```javascript
   // 修改 chat-sender.js 第 101 行
   headers: {
     'Content-Type': 'application/json',
     'X-Requested-With': 'XMLHttpRequest'
   }
   ```

---

### Q3: HTTP 403 Forbidden

**原因：** 权限不足或认证失败

**解决方案：**

1. **检查 cookie 是否存在**
   ```javascript
   console.log(document.cookie);
   ```

2. **重新登录闲鱼**
   - 退出登录
   - 清除 cookie
   - 重新登录

3. **检查是否需要 CSRF token**
   - 查看其他请求是否有特殊 header
   - 可能需要添加 `_token` 或类似字段

---

### Q4: HTTP 500 Internal Server Error

**原因：** 服务器错误，可能是数据格式不对

**解决方案：**

1. **检查 payload 格式**
   - 对比你提供的原始抓包数据
   - 确保所有字段都正确

2. **检查 base64 编码**
   ```javascript
   var testData = {"contentType":1,"text":{"text":"测试"}};
   console.log(btoa(JSON.stringify(testData)));
   ```

3. **检查 sessionId 和 receiverId 格式**
   - 应该是数字字符串
   - 需要加 `@goofish` 后缀

---

### Q5: 请求成功但没有回复

**可能原因：**
- 响应数据解析失败
- 响应格式不符合预期
- 异步回调没有执行

**排查方法：**

1. **查看完整日志**
   ```javascript
   // 在控制台执行
   console.log('检查所有 [消息发送] 开头的日志');
   ```

2. **检查 Promise 链**
   ```javascript
   // 手动测试
   window.XianyuSender.sendTextMessage(...)
     .then(result => console.log('成功:', result))
     .catch(error => console.error('失败:', error));
   ```

3. **检查 auto-reply-processor 的回调**
   ```javascript
   // 应该能看到：
   // [自动回复] ✅ 回复成功
   // 或者
   // [自动回复] ❌ 回复失败
   ```

### 2. 监控网络请求

```javascript
// 使用 Performance API
performance.setResourceTimingBufferSize(1000);

// 监听请求
new PerformanceObserver((list) => {
  list.getEntries().forEach((entry) => {
    if (entry.name.includes('sendByReceiverScope')) {
      console.log('📡 捕获到请求:', entry);
    }
  });
}).observe({entryTypes: ['resource']});
```

---

### 3. Hook Fetch API

```javascript
// 保存原始 fetch
const originalFetch = window.fetch;

// 替换为带日志的版本
window.fetch = function(...args) {
  console.log('🔍 Fetch 被调用:', args);
  return originalFetch.apply(this, args)
    .then(response => {
      console.log('📥 Fetch 响应:', response.status);
      return response;
    })
    .catch(error => {
      console.error('❌ Fetch 错误:', error);
      throw error;
    });
};
```

## 🆘 仍然无法解决？

### 收集以下信息寻求帮助：

1. **完整控制台日志**（截图或复制文本）
2. Network 面板中的请求详情（截图）
3. 响应内容（如果有）
4. 执行的测试步骤
5. 闲鱼页面 URL

### 可能的根本原因：

根据经验，最可能的原因是：

1. **扩展未正确重新加载** → 刷新扩展并重新测试
2. **代码有语法错误** → 检查控制台红色错误
3. **权限/CORS 问题** → 检查 Network 面板
4. **数据格式不对** → 对比原始抓包数据
5. **异步回调未执行** → 检查 Promise 链
