### ✅ 4. 防重复回复机制（✅ 已实现）

**文件位置：** `inject/processors/auto-reply-processor.js`

**机制：**
- ✅ 检查发送人是否是自己（避免循环回复）
- ✅ 记录已处理的消息 ID（不重复处理同一条消息）
- ✅ 冷却时间设置（默认 60 秒内不重复回复同一用户）
- ✅ 黑名单功能（可禁用特定用户的自动回复）

**关键代码：**
```javascript
// 检查是否是自己的消息
if (message.direction === 'out') {
  return false; // 跳过自己发送的消息
}

// 检查冷却时间
var lastTime = runtime.lastReplyTime[message.senderId] || 0;
if (now - lastTime < runtime.config.cooldown) {
  return false; // 冷却时间内跳过
}
```

### API 实现细节

**请求 URL:**
```
POST https://www.goofish.com/r/MessageSend/sendByReceiverScope
```

**请求体结构:**
```javascript
{
  lwp: '/r/MessageSend/sendByReceiverScope',
  headers: {
    mid: '时间戳 0'
  },
  body: [
    {
      uuid: '-时间戳 + 随机数',
      cid: 'sessionId@goofish',
      conversationType: 1,
      content: {
        contentType: 101,
        custom: {
          type: 1,
          data: base64(JSON.stringify({
            contentType: 1,
            text: { text: '消息内容' }
          }))
        }
      },
      // ...其他字段
    },
    {
      actualReceivers: ['receiverId@goofish']
    }
  ]
}
```

**关键参数:**
- `sessionId`: 会话 ID（格式：数字）
- `receiverId`: 接收者 ID（格式：数字）
- `content`: 消息内容（文本）
- `contentType`: 101（文本消息）
- `cid`: sessionId + '@goofish'
- `actualReceivers`: [receiverId + '@goofish']

**认证方式:**
- 通过 `credentials: 'include'` 自动带上 cookie
- 不需要额外的 token 或 header

```

    ↓
ChatParser 解析 (chat-parser.js)
    ↓
EventBus 发出 chat:message 事件
    ↓
AutoReplyProcessor 监听并匹配关键字
    ↓

    ↓

    ↓
发送到闲鱼服务器 (fetch API)
    ↓
收到响应
    ↓
记录日志并更新状态
```
