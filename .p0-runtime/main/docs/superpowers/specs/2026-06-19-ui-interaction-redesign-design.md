# 闲鱼数据采集助手 — UI 与交互改进设计

- **日期**：2026-06-19
- **状态**：待实现
- **目标**：改进 UI 与交互，移除不必要的、保留使用的功能，核心是「容易上手」
- **使用场景**：对外发布分发，面向陌生用户，首屏即需看懂

## 1. 背景与现状

项目为 Chrome MV3 扩展「闲鱼数据采集助手」，三个 UI 入口：

1. **Popup（工具栏弹窗，400px）** — 关键词输入 + 开始采集；下方一排四个同级按钮（配置 / 导出 / 飞书 / 清空）；流量词展示区；飞书状态区。
2. **配置中心（options 页）** — 左侧导航四项：爬取设置 / 代理设置（空占位）/ 高级设置（空占位）/ 飞书设置。
3. **商品详情页浮动按钮** — 右下角 ⬇️ 下载 + 📋 下载记录控制台（含「🚀 发布」按钮）。

**现状问题**：
- 功能未分层：popup 一排四按钮里「清空」（破坏性）与「导出」同级；新用户认知负担大。
- emoji 图标（🐟 ⬇️ 📋 🚀）跨平台显示不一致，观感廉价。
- 视觉缺乏质感：边框硬、留白不足、字体层级模糊。
- 版本号不一致：`manifest.json` 为 `1.5.0`，popup 角标为 `v1.7.0`。

## 2. 设计决策（已与用户确认）

| 决策点 | 选择 |
|---|---|
| 使用场景 | 对外发布分发 |
| 核心流程 | A 批量采集为主（popup 为主角，详情页为辅） |
| 主输出 | CSV 为主，飞书可选 |
| 改造思路 | 方案二：分层引导（渐进式披露） |
| Popup 布局 | 方案 A：结果区主操作 + 状态栏同行「⋯ 更多」入口 |
| 视觉风格 | 方向 2：品牌鲜明（黄色用得更满，图标带品牌色） |
| 图标体系 | 全站统一 SVG 线性图标，移除 emoji |
| 版本号 | 统一为 `1.7.0` |

## 3. Popup 重设计

### 3.1 布局（方案 A）

自上而下：

1. **头部**：鱼形 SVG 图标 + 「闲鱼数据采集」标题 + 版本角标 `v1.7.0`。
2. **状态栏**：`● 运行中 · 已采 X 件 · 第 X 页`，右侧为「⋯ 更多」入口（SVG 更多图标）。
   - 「⋯ 更多」为下拉菜单，内含两项：配置中心、清空数据。点击外部区域关闭。
3. **采集行**：关键词输入框（带搜索 SVG 前缀图标）+ 「开始」主按钮。
4. **结果区（采集完成后出现）**：`导出 CSV`（主按钮，黄色填充）+ `飞书`（次级按钮，描边/弱化）。
5. **流量词区**：采集后自动展开，标签流式排列，点击整行复制全部（保持现状行为）。

### 3.2 交互

- 「清空」从主操作行移除，收进「⋯ 更多」，避免破坏性操作与日常操作同级。
- 「飞书」按钮降为次级视觉，明确它是可选输出（CSV 为主）。
- 未采集时状态栏给出引导文案：「输入关键词，点开始采集」。

### 3.3 视觉（方向 2 · 品牌鲜明）

- 主色 `#ffe60f`（闲鱼黄），用得更满：主按钮黄色渐变（`linear-gradient(135deg,#ffe60f,#ffd000)`），带柔阴影 `0 2px 6px rgba(255,210,0,.4)`。
- 状态栏采用浅黄底 `#fffdf2` + 黄边 `#ffe60f`，强化品牌采集感。
- 版本角标：浅黄底 `#fff8e1` + 深黄字 `#b8860b`。
- 次级图标带品牌色（黄色系）。
- 圆角 9px，统一 8px 间距网格；柔阴影 `0 1px 2px rgba(15,23,42,.05), 0 12px 32px rgba(15,23,42,.08)`。
- 字体：PingFang SC / -apple-system；正文 12–13px，标题 14px/600。

## 4. 配置中心（options）重设计

### 4.1 结构（保持不变）

- **左侧导航保留全部 4 项**：爬取设置 / 代理设置 / 高级设置 / 飞书设置。（代理、高级空占位**不移除**，留待后续填充。）
- 「爬取设置」+「过滤条件」仍合在一个面板（起始页码 / 采集页数 / 间隔时间 / 最小想要数 / 最小价格 / 最大价格 / 只看包邮）。
- 「飞书设置」面板标题标注「（可选）」，明确非必需。

### 4.2 视觉与配套

- 套用方向 2 视觉规范（黄色点缀、SVG 图标、柔阴影、9px 圆角）。
- 飞书页保留「测试连接」按钮 + 行内说明文案，降低配置门槛。
- 修复版本号不一致：`manifest.json` 与 popup 角标统一为 `1.7.0`。

## 5. 商品详情页浮动按钮重设计

### 5.1 结构（保持不变）

- 右下角两个浮动按钮：下载、记录控制台（位置、尺寸、悬停 tooltip 行为保持现状）。
- 控制台表格结构不变（商品图 / 标题 / 价格 / 发布时间 等）。
- 记录中「发布」按钮保留，作为次级动作（一键发布/搬砖）。

### 5.2 视觉调整

- emoji 全换 SVG 线性图标：⬇️→下载图标、📋→列表图标、🚀→发送图标，与 popup 统一。
- 现有配色（深色 `#1f1f1f` 底 + 黄色 `#ffe60f`）天然契合方向 2，保留。
- 套用方向 2 的柔阴影、圆角、间距规范，与 popup/options 视觉一致。
- 「发布」按钮视觉明确降为次级（描边/弱化），与主操作区分。

## 6. 图标体系（全站统一）

统一 SVG 线性图标集（stroke 风格，currentColor 着色），替换所有 emoji：

| 用途 | 原 emoji | 新 SVG 图标 |
|---|---|---|
| 品牌标识 | 🐟 | 鱼形 |
| 搜索/关键词 | — | 放大镜 |
| 下载/导出 | ⬇️ | 下载（托盘+箭头） |
| 飞书/发送 | — | 纸飞机 |
| 更多入口 | — | 三点（⋯） |
| 设置 | — | 齿轮 |
| 列表/记录 | 📋 | 列表 |
| 发布 | 🚀 | 发送 |

图标以 inline SVG `<symbol>` + `<use>` 方式在各页面内定义并引用（不引入外部 SVG 文件，规避扩展 CSP 与 fetch 问题），统一描边宽度（约 1.8–2px）与尺寸（14–16px）。

## 7. 上手引导与一致性

- **空状态引导**：
  - popup 未采集时：状态栏文案「输入关键词，点开始采集」。
  - 控制台无记录时：补一句「在商品详情页点下载，记录会出现在这里」。
- **一致性**：全站统一 SVG 图标体系、方向 2 视觉规范（主色 `#ffe60f`、柔阴影、9px 圆角、统一字号字重），贯穿 popup / options / 详情页。
- **版本号**：`manifest.json` 与 popup 角标统一为 `1.7.0`。

## 8. 不引入的内容（YAGNI）

- 不加新手向导弹窗 / 教程页 / 多语言切换。
- 不重构采集、飞书同步、发布等业务逻辑——本次只动 UI 与交互层。
- 不移除代理设置、高级设置导航项（保留占位待后续）。
- 不改浮动按钮位置/尺寸、不改控制台表格结构。

## 9. 涉及文件（预估）

- `popup.html` / `popup.js` — 布局重组、按钮分层、图标替换、空状态文案、视觉规范。
- `options.html` / `options.js` — 视觉规范套用、飞书标注「可选」、版本号。
- `item-download.js` / `item-download.css` — emoji→SVG、视觉规范对齐、发布按钮降级。
- `manifest.json` — 版本号统一为 `1.7.0`。
- 各页面内新增 inline SVG `<symbol>` 图标定义（无独立图标文件）— 统一 SVG 图标集。

## 10. 验收标准

1. popup 主路径（关键词→开始→导出 CSV）一目了然，清空/配置收进「⋯ 更多」。
2. 全站无 emoji，统一为 SVG 线性图标，跨平台显示一致。
3. 三处界面视觉统一（方向 2 规范：黄色主色、柔阴影、9px 圆角、统一字重）。
4. 配置中心保留 4 导航项，飞书标注「可选」。
5. 详情页浮动按钮位置/尺寸不变，「发布」为次级视觉。
6. `manifest.json` 与 popup 角标均为 `1.7.0`。
7. 未采集 / 无记录时有引导文案。
8. 采集、导出、飞书同步、下载、发布等业务功能行为不变。
