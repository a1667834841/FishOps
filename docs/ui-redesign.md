# 工作台界面改版

## 版本基线

工作台在独立 Git 仓库中维护，改版前基线为 `4d45ed9`。该提交包含当时的工作台、扩展、共享协议与历史参考资料；依赖和构建产物不纳入 Git。

## 设计与布局

按 `redesign-existing-projects` 的审查方法整理信息层级：移除首页介绍大卡、研发阶段标记、演示数字与虚构活动。界面使用闲鱼黄 `#FFE60F`、中性黑白灰和统一 Phosphor 图标。黄色用于主操作与选中状态，正文采用高对比文字色。

- 商品库保留来源筛选、真实图片、分页、导出和飞书写入。字段同步及写入预览、确认采用弹窗，原有冲突拦截、预览过期、显式确认保留。
- 采集采用分页任务列表，新建任务与任务详情使用弹窗。列表显示“已加载”数量，避免将分批加载的记录冒充完整历史；支持加载更多和每页数量选择。
- 分析采用配置栏和结果栏；规则新建、编辑使用弹窗。回复规则编辑也采用弹窗。
- 设置采用分区导航，通过 `v-show` 保留未保存草稿。
- 聊天扩大消息区域，消息、会话独立滚动；窄屏买家商品信息按需展开。
- 发布保留当前显式提交和防重复操作机制，仅调整图标、文案与布局。

弹窗使用原生 `dialog`，提供标题、关闭按钮、Escape 操作、初始表单焦点和关闭后的焦点恢复。执行写入或保存时禁止关闭，避免误判操作是否完成。新用户默认浅色，已有主题偏好保留，支持深色与系统主题。

## 真实概览口径

首页仅发起只读请求：商品总数通过 `PRODUCT_LIST` 的 `total` 读取，未读会话按 `unreadCount > 0` 统计。采集、分析读取共享任务存储，发布读取独立的发布存储；合并完整列表后统计运行中与失败任务，按更新时间显示最近八条。

数据源分别处理加载与失败；首次失败不会显示零，刷新失败保留最近数据及时间。事件合并窗口为 300ms，页面卸载清理订阅与计时器。非扩展页面不发送业务命令，不显示演示数据。

## 验证

整项目类型检查、工作台测试与工作台生产构建通过。工作台共 175 条测试，包含六条新增概览测试，覆盖全量口径、部分失败、发布结果截断、竞态、事件合并、卸载与非扩展环境。

业务页采用按需加载，避免所有业务表单和控制器进入首页入口包。构建输出位于 `extension/dist`。本地预览为 `http://127.0.0.1:5174/workbench.html`。

浏览器审查空间由用户接管，未获得恢复操作的答复，因此本次未完成浏览器截图、断点视觉验收和真实扩展数据的交互验收。现有检查不替代这些验收。
