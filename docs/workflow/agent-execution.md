# 代理执行

- 上下文充分、范围局部或串行依赖强时直接执行。独立调研、定向 review 或专门能力有明确收益时委派；不为阶段拆分派工。
- 首次派工写明目标、绝对目录、已有证据、允许修改范围、验收、必要检查及停止条件；不重复调查已知证据。
- 一个目标默认一个执行代理完成取证、回归、实现、检查与原入口复测。验收满足即返回；仅失败、新证据或影响扩大时增加工作。
- 仅独立任务、无文件冲突且有明确收益时并行。UI 优先 gemini-3.8-flash-high，通用优先 deepseek-v4.1-flash，gpt-6-luna 兜底。
- 执行代理默认不递归派工；确有收益需拆分时向主代理说明。
- 主代理定向 review，复用未改动代码的有效检查；遗漏优先由原代理修正，只重跑受影响检查。编排越界时修正规范。
