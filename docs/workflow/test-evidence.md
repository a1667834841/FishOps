# 验证证据与截图

- 证据文档记录 Issue、worktree/分支、Commit、验收动作、状态、可见结果与副作用；检查记录命令、目录、代码状态、退出码及摘要。长日志保存本地，不因输出截断重复运行。
- 单测、Mock、真实 E2E、本地检查及 CI 分层记录；缺失真实数据的边界标为未覆盖，不包装为真实通过。
- 页面视觉或交互普通 PR 必须附最终代码在真实环境的代表截图；Draft 因环境阻碍缺图时说明原因及补验计划。触发目标状态再截图，关闭按钮等目标需可见。覆盖受影响布局、尺寸、比例、行高与滚动，不遍历无关页面。
- 截图检查敏感信息，只裁切或遮盖敏感区域并说明，不替换业务内容；无法安全公开时请用户决策。
- 图片保存 `docs/images/`，在验收文档与 PR 直接展示，注明入口、状态及验证边界；GitHub 链接指向包含图片的实际提交或稳定资源。
- 页面代码变化后重新部署、复测并换图；Mock 图不能作最终效果图。
