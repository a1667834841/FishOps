# test：测试

- A：核对内容、链接、diff；纯文档免应用检查，源码文案构建受影响包。
- B：定向回归后运行 `npm run regression`。
- C、D：定向回归后运行 `npm run regression:full`及业务[真实 E2E](test-e2e.md)，见[回归范围](../regression-testing.md)。
- 单测覆盖真实输入、类型、正常、失败、重试与再次操作；验证卸载、监听、在途请求和计时器清理。外部依赖及写入用 Mock，计时器用 fake timer；字符串只断言关键结构。
- Mock 不替代真实 E2E；纯逻辑不启动浏览器。
- 代码必须构建；跨包变化扩大检查。修改后验证，代码未变复用结果；本地与 CI 分开报告。
- 按[证据规范](test-evidence.md)记录；代码失败回 coding。环境阻碍保留失败或未执行状态，标待验收。

检查与验收通过交付普通 PR；仅环境、账号或配置阻碍验收时，实现及本地必要检查完成后交付 Draft PR，列明阻碍、未验项及恢复步骤。进入 pr review，待验收不可合并。
