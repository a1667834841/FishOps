# test：测试

- A：核对内容、链接与 diff；纯文档免应用测试、typecheck、构建和浏览器。源码文案仍构建受影响包。
- B：定向回归后运行 `npm run regression`。
- C、D：定向回归后运行 `npm run regression:full`，再补受影响业务的[真实 E2E](test-e2e.md)。范围见[回归测试](../regression-testing.md)。
- 单测使用真实输入与边界，覆盖运行时类型、正常、失败、重试及再次操作；涉及卸载、监听、在途请求与计时器时验证清理。依赖与外部写入用 Mock，计时器用 fake timer；字符串只断言关键结构。
- Mock 页面属于开发验证，不能替代最终 E2E。纯逻辑不启动浏览器。
- 代码交付必须实际构建；共享协议或跨包依赖变化扩大检查。最终修改后验证，代码未变复用有效结果；本地与 CI 分开报告。
- 按[证据规范](test-evidence.md)记录。失败回 coding；环境阻碍标待验收。

验收与必要检查全部通过、无未解释失败后提交 PR，进入 pr review。
