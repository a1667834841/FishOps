# done：合并完成

- 通过 GitHub 查询核实任务对应 PR 的状态为 `MERGED`，记录合并提交与链接；Reviewer 同意、CI 通过或开发完成均不能代替合并证据。
- 确认验收目标与审核意见已处理，再将任务工作区状态设为 `completed`，读回确认。PR review 交付后由人工合并；后续会话恢复或检查任务时补同步。
- 汇报合并结果与证据。关闭 Issue 以实际结果为准，不因移动看板而宣称已关闭。
- Done 只表示任务完成；不自动删除分支、工作区或停止终端，清理按已有授权执行。
- PR 未合并保留 pr review；关闭但未合并时报告原因，不进入 done。新增需求按新任务或回 plan 处理。
