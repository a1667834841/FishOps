# 测试授权

- 用户已授权当前项目测试账号的真实业务验收，包含发布测试商品；相同环境与操作范围的授权跨轮次、跨代理沿用，不重复询问。
- 发布使用测试素材，记录结果、商品链接与可见状态。发布链路变化执行专项真实发布；普通回归不固定重复发布。
- 真实发送消息、删除数据和生产账号操作须另有授权，不能从测试发布授权推导；破坏性场景在可恢复测试副本执行。
- 同一任务从取证、部署、复测到截图保持同一浏览器空间，验收结束后关闭。用户实际接管、停止或撤销授权时立即停止。
- 当前部署脚本完成后仍调用 `task.finish()`；用户已授权恢复仅由本项目部署脚本主动结束的空间，继续同一任务。此授权不适用于用户接管或主动停止；文档不代表脚本已修复。
