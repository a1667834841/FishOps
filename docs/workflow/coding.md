# coding：编码实现

- 从最新主分支建立独立 worktree 与任务分支；已有合适工作区或自动化已创建时复用。执行会话、代码及验收记录绑定同一任务工作区，核对后实现。
- 先读现有脚本及构建配置，确认命令、产物和真实入口。
- Bug 先建立失败可执行回归再修复；需求先补验收断言再实现。A 路径使用内容检查。
- 最小完整实现，核对调用契约、真实输入、状态传递及生命周期清理；不顺便重构。遵守 AGENTS.md 的中文注释规范。
- 需要代理时读[代理执行](agent-execution.md)，同一执行代理闭环，主代理复核证据。
- 命令失败先分析；最多尝试三次，每次调整方案。同一错误无新证据停止。范围扩大先报告；授权或账号阻碍待人工处理。

实现覆盖验收目标、回归能解释原问题、diff 可审查后进入 test。无关发现记录为后续事项。
