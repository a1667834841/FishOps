# M5 发布实现与验证记录

日期：2026-10-18。状态：实现与离线回归已通过；真实发布业务 E2E 仍未完成，不能将本记录视为发布验收证据。

## 已修复

- 公共 API 仍要求幂等键；内部 prepare/submit 单步使用独立 schema，不再被公共必填字段阻断。
- 页面按内部 prepareRef 保存权威上下文，并按与 Host 相同的规范输入计算授权指纹。
- Host 保存 prepare 的固定页面上下文；页面刷新或文档变化后拒绝提交，不能自动迁移旧授权。
- URL 图片必须经过真实上传适配；下载正文与图片解码纳入超时，不回退到源图直接提交。
- 数字售价、数字坐标、协议相对图片地址有定向回归；违禁词预检先于上传。
- 显式规格覆盖用于最终描述；地址引用必须匹配官方 selectedPoi 的 poiId。
- 明确风控与登录错误保留分类，发布路由写入 risk.signal；未知写结果仍不自动重试。

## 存储边界

MAIN world 不具有 chrome.storage.session 权限。错误的直接接线已移除。
会话存储适配器目前只有离线测试，尚未接入可信扩展内部通道，不能声称已支持跨页面恢复。
生产目前使用文档内存；SW/native 重连不销毁页面数据，页面刷新后必须重新 prepare。
