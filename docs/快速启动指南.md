# 🚀 自动回复功能 - 快速启动指南

## ✅ 前提条件

- [x] 扩展已安装并启用
- [x] 可以访问闲鱼聊天页面
- [x] 有测试用的另一个账号

## 📋 5 分钟快速测试

### Step 1: 重新加载扩展 (30 秒)

1. 打开 `chrome://extensions/`
2. 找到 "闲鱼聊天监听助手"
3. 点击刷新按钮 🔄
4. 确认无错误提示

---

### Step 2: 测试消息发送功能 (2 分钟)

#### 方法 A: 使用测试脚本（推荐）

```javascript
// 1. 打开闲鱼聊天页面
// 2. F12 打开控制台
// 3. 粘贴以下代码并回车

fetch(chrome.runtime.getURL('inject/api/test-send-message.js'))
  .then(res => res.text())
  .then(code => eval(code));
```

**预期结果：**
```

📤 开始发送测试消息...

⏳ 等待发送结果...

========== 发送结果 ==========

✅ 发送成功！
📝 消息 ID: -17714256815401
📊 完整响应：{...}

================================
```

**如果失败：**
- ❌ XianyuSender 未定义 → 检查扩展是否注入成功
- ❌ 网络错误 → 检查网络连接
- ❌ 权限错误 → 确保在闲鱼域名下

---

### Step 3: 配置自动回复规则 (1 分钟)

1. **打开设置页面**
   - 右键点击扩展图标
   - 选择"选项"

2. **添加关键字规则**
   ```
   触发关键字：123
   回复内容：456
   ```

3. **启用自动回复**
   - 打开"启用自动回复"开关（绿色）
   - 点击"保存设置"按钮

4. **验证配置**
   - 看到"✅ 设置已保存"提示
   - 规则列表显示刚才添加的规则

---

### Step 4: 实际测试 (1 分钟)

1. **用另一个账号登录闲鱼**
2. **进入聊天窗口**（和你的主账号聊天）
3. **发送消息：** `123`
4. **等待 1-2 秒**
5. **查看是否收到回复：** `456`

**成功标志：**
- ✅ 收到自动回复 "456"
- ✅ 控制台显示 "[自动回复] ✅ 回复成功"

## ⚙️ 高级配置

### 多关键字回复

在设置页面添加多个规则：

| 触发关键字 | 回复内容 |
|-----------|---------|
| 你好 | 您好！有什么可以帮您？😊 |
| 在吗 | 您好，请问有什么事吗？ |
| 价格 | 这个价格是实价哦~ |
| 包邮 | 亲，不包邮呢~ |

### 延迟和冷却时间

**回复延迟：** 1000ms（1 秒）
- 模拟真人回复速度
- 避免显得太机械

**冷却时间：** 60 秒
- 同一用户 60 秒内只回复一次
- 防止被判定为机器人

### 黑名单功能

如果遇到不想回复的用户，将其 ID 加入黑名单：

```javascript
// 在控制台执行
window.AutoReplyProcessor.addBlacklist('用户 ID');
```

## 🔧 故障排查

### Q1: 没有收到自动回复

**检查清单：**
- [ ] 自动回复开关是否打开？
- [ ] 是否配置了关键字规则？
- [ ] 消息内容是否完全匹配？（区分大小写）
- [ ] 是否在冷却时间内？
- [ ] 控制台是否有错误日志？

**调试步骤：**
```javascript
// 1. 检查处理器状态
console.log(window.AutoReplyProcessor.getStatus());

// 2. 手动启用
window.AutoReplyProcessor.enable();

// 3. 添加测试规则
window.AutoReplyProcessor.addKeyword('test', 'reply');
```

---

### Q2: 发送消息失败

**常见错误：**

**错误 1: Network Error**
```
原因：网络连接问题
解决：检查网络，刷新页面
```

**错误 2: 403 Forbidden**
```
原因：权限不足或 cookie 失效
解决：重新登录闲鱼
```

**错误 3: XianyuSender is not defined**
```
原因：扩展未正确注入
解决：重新加载扩展，刷新页面
```

---

### Q3: 循环回复（A 回复 B，B 又回复 A）

**原因：** 两个账号都开启了自动回复

**解决方法：**
1. 只在其中一个账号开启自动回复
2. 或者设置不同的关键字避免循环

**防护机制：**
- ✅ 系统会自动检测自己的消息
- ✅ 不会回复自己发送的消息

## 📊 性能优化建议

### 1. 合理设置冷却时间
- 个人使用：60 秒
- 商家客服：30 秒
- 高频场景：10-15 秒（谨慎使用）

### 2. 精简关键字规则
- 只保留常用回复
- 避免过多规则影响性能
- 定期清理无用规则

### 3. 定期检查日志
- 每周查看一次控制台
- 清理异常记录
- 优化回复策略
