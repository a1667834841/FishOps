# 商品描述与商品库缓存

## 商品描述

- 新建采集任务默认读取商品详情。详情中的描述写入本地商品记录，并写入飞书的「商品描述」文本字段。
- 搜索列表的商品标题不等于商品描述。缺少描述时，不应把标题当作真实详情。
- 旧飞书表需要先通过字段一致性检查补齐「商品描述」字段，再执行写入。
- 已经采集且描述为空的旧记录不会自动恢复。需要在飞书旧记录或发布草稿中手动补录真实描述。重新采集可以补齐本地详情，但飞书写入会跳过去重键相同的已有记录，不会自动覆盖旧行。
- 用户关闭详情采集，或者详情接口失败时，记录仍可能缺少描述。发布前应检查描述内容。

## 商品库缓存

- 飞书商品库和当前账号发布商品库采用异步读取。普通打开和切换选项卡不应强制重新读取远端数据。
- 首页结果应复用缓存。采集完成或发布成功后，在后台异步刷新受影响的缓存。
- 采集进度、暂停和等待发布确认不代表数据已经更新，不应触发完成刷新。
- 手动刷新用于重新读取远端数据，例如飞书记录被外部修改之后。
- 缓存必须隔离闲鱼账号和飞书配置。旧请求不能覆盖切换后的新数据。
