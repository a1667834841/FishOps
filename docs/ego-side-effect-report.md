## A. 聊天发送「你好」一次 — FAIL（真实尝试一次，被扩展拒绝，未发出）

- 目标会话：Workbench 聊天中心**第一个会话**，显示名 **「未来星罕见的饺子」**（发送前、发送时均确认仍为列表第一条）。
- 操作序列：
  1. 选中第一个会话（消息记录已渲染）；
  2. 点「启用发送」（回复区解锁，`发送已锁定` → 已解锁）；
  3. 在「手动发送」输入框填入 **「你好」**（发送前确认 `textarea.value === "你好"`、已解锁、第一个会话未变）；
  4. 点击「发送」**一次**。
- 结果：**失败**。扩展返回提示「扩展拒绝了这次请求（当前用户 ID 未就绪，无法发送）」；消息记录**无新增**，输入框文本未清空。
- 时间：发送动作 **2026-10-02T15:20:18.910Z（= 23:20:18 本地）**。
- 错误摘要：`当前用户 ID 未就绪，无法发送`（`reply-runtime` 返回，code `INVALID_PAYLOAD`）。
- 根因（读代码，未改代码）：`myUserId` 由 `platform.call(CURRENT_USER_ID)` 获取，带 4s 超时且**失败结果在 service worker 生命周期内被缓存为 undefined**；本空间仅有 Workbench 内页、无已登录闲鱼页面，故取不到用户 ID。该缓存机制使本轮内重试必然同样失败。
- 合规：按「只发一次/不重复发送」「失败不重试超过一次（此处重试无意义且属重复发送）」及「不重载/不卸载扩展」，**未再点击发送**，未启用自动回复，未发送其它文本。
- 判定：**FAIL**（真实发送一次未成功；恢复条件见「需用户介入」）。
